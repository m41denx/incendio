IncusCloud is a control plane for [Incus](https://linuxcontainers.org/incus/). Put it in front of
your clusters and standalone servers, and they become one private cloud:

- **One sign-in.** People sign in once, in the browser or with the stock `incus` CLI. The same token
  works against every cluster.
- **One console.** An inventory of every cluster, member, project and instance, with each cluster's
  own UI ([Incendio](https://github.com/m41denx/incendio)) built in.
- **One API endpoint per cluster.** `https://prod.clusters.example.com` is cluster `prod`. Every
  request goes through as the person who made it, and each cluster still enforces their
  permissions itself.

On top of that, IncusCloud adds what a single Incus cluster doesn't have:

## Nothing to install on the clusters

IncusCloud talks to each cluster over its normal HTTPS API. When you enrol a cluster, it sets the
cluster's sign-in (OIDC) and permission checks (OpenFGA), and creates a restricted project for each
tenant you place there. There are no agents, appliances or extra packages on the Incus hosts.
