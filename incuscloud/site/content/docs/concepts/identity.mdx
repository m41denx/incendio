IncusCloud keeps its own users. [Ory Hydra](https://www.ory.sh/hydra/) issues their tokens, and
IncusCloud serves Hydra's login, consent and device-code pages.

## Users

A user is an email address and a password. Platform administrators add them under **Users**, and
tenant admins add people to their tenants by email. The first administrator is created from
`IC_BOOTSTRAP_ADMIN_EMAIL` and `IC_BOOTSTRAP_ADMIN_PASSWORD` while there is no administrator yet.

## How each client signs in

| Client | Flow | What it holds |
| --- | --- | --- |
| Browser | Authorization code, handled by IncusCloud | A server-side session cookie |
| `incus` CLI | Device code: the CLI prints a link, you sign in in the browser | An access token and a refresh token, refreshed by the CLI |
| Service account | Client credentials | A short-lived access token it asks for itself |

Access tokens are JWTs with audience `incuscloud`. The clusters verify them themselves against
Hydra's published keys, which is why every cluster member has to reach the public URL.

## Service accounts

Service accounts are identities for automation: CI, Terraform, scripts. Each has a client ID and a
secret, shown once when it is created and again only when you rotate it. They get permissions like
users do.

- A **tenant** service account belongs to one tenant and is managed by that tenant's admins.
- A **platform** service account belongs to no tenant and is managed by platform administrators.

To get a token:

```bash
curl -s -u "$CLIENT_ID:$CLIENT_SECRET" \
  -d grant_type=client_credentials -d audience=incuscloud \
  https://cloud.example.com/oauth2/token
```

Use it as `Authorization: Bearer <token>` against the IncusCloud API or any cluster's endpoint.

## Platform roles and tenant roles

Two sets of roles are edited where you'd expect them:

- **Platform roles** on the Users page: admin, operator and viewer.
- **Tenant roles** on a tenant's page: owner, admin, member and viewer.

Both are part of the [permissions](/docs/concepts/permissions) model: each is read as an entry on
`/` or on the tenant.
