<Steps>
<Step>

### Sign in

Open `https://cloud.example.com` and sign in with the admin email. The password is:

- **Compose:** `IC_BOOTSTRAP_ADMIN_PASSWORD` in `incuscloud.env`;
- **Helm:** the `admin-password` key of the `incuscloud` secret.

Change it right away: your name at the bottom of the side menu opens **Profile**.

The bootstrap settings create an administrator only while there is none, so it's safe to leave them
in place.

</Step>
<Step>

### Enrol a cluster

On the cluster, as an Incus administrator:

```bash
incus config trust add incuscloud --quiet
```

In IncusCloud, **Clusters** › **Enrol cluster**: a name, which becomes
`https://<name>.clusters.example.com`, the token, and optionally labels. See
[Clusters](/docs/incuscloud/guides/clusters) for what happens next.

With the internal CA, make sure every member of the cluster trusts `ca.crt` before anyone signs in
to it.

</Step>
<Step>

### Create a tenant

**Tenants** › **Create tenant**, then on the tenant's page:

- place it on the cluster;
- set its quotas;
- add members by email.

See [Tenants](/docs/incuscloud/guides/tenants).

</Step>
<Step>

### Add people

Add users under **Users**, give platform staff a platform role, and fine-grained access under
**Permissions**. See [Users, groups and permissions](/docs/incuscloud/guides/access).

</Step>
</Steps>
