## Notes

- **Operator** lacks only `acl.manage`, `platform.users` and `platform.settings`.
- **Cluster owner** and **Group owner** hold `acl.view` and `acl.manage`, so they manage permissions
  on their cluster or group.
- **Unrestricted user** holds every workload privilege, but no `node.*`, `cluster.configure` or
  `acl.*`. It can't be given on a whole cluster or `/`: there it would reach every tenant's
  projects.
- **User** holds a few privileges everywhere it is given (creating, using networks and storage,
  seeing the tenant's shared objects) and the rest only on what it owns.
- Only administrators give **Administrator** or **Cluster owner**.
