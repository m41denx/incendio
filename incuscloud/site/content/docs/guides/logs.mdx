## Audit log

Every change made through IncusCloud's API: the time, the actor, the action (such as
`tenant.create`), the target, the result and the client's address. Filter by tenant, actor and
action.

- Platform viewers see the whole log.
- Tenant admins see their tenant's, with `?tenant=`.

## Gateway log

Requests that went through the gateway to a cluster: the time, cluster, actor, method, path, status,
bytes in and out, and duration. It records every change, every websocket and file transfer, and a
sample of reads set by `IC_GATEWAY_SAMPLE_READS` (0 by default, from 0 to 1). Filter by tenant and
cluster.

Same visibility as the audit log.

<Callout title="Retention">
  Neither log has a retention limit yet. Watch the database's size; see
  [Security](/docs/operations/security#known-limits).
</Callout>
